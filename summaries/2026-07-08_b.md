  - แผน launch ของ 1BX และ timeline ขึ้น production

## เนื้อหาสำคัญ

- **เทคนิค/Infra:** มีคำถามเรื่อง Execution Mode และการคำนวณ memory — ทีมยังไม่เคย provision เครื่องเอง ใช้ VM/Cloud; พี่ฟี่แนะว่าถ้า error เป็นเรื่องสเปค ต้องไปทดสอบบน environment จริง จะสร้างเป็น workload ใน cluster (GKE) หรือแยกเป็น VM ก็ได้ มีการเทียบกับ Azure ที่มีบริการ testing (ถามหา service เทียบเท่าบน GCP) และย้ำให้เช็คค่ารันจริงบน GCP
- **สรุปขอบเขต consult:** ทีมมองว่าหัวข้อที่ผ่านมาครอบคลุมเกือบครบ (security, sustainability, เอกสาร, AI Knowledge) เหลือโซน "ต้นทุน" ที่ยังไม่ค่อยได้คุย — อยากรู้ว่าจะประหยัด cost ได้อย่างไร (ปัจจุบันมีฝั่ง dev relation/พี่ยกช่วยดูแลและ consult อยู่แล้วบางส่วน)
- **Man-hour ที่ปรึกษา:** พี่ฟี่ชี้แจงว่าโควตาคือ 35 ชั่วโมง/เดือน (lock ขั้นต่ำต่อเดือน) ถ้าใช้เกินพี่ฟี่รับเอง — ที่ผ่านมาเกินเล็กน้อย; ฝั่งทีมยืนยันว่าใช้เต็มที่และมีประสิทธิภาพ
- **Feedback:** พี่ฟี่ขอ feedback ว่าความรู้ที่ให้ไปได้นำไปใช้จริงไหม/มีประโยชน์ไหม — มีการทำฟอร์มเก็บ feedback แยกตามโปรเจกต์แล้ว (อยู่ที่คุณบี) และบางคนกรอกส่งแล้ว
- **แผน 1BX:** ยังอยู่ใน development stage — สิ้นเดือนนี้ (ก.ค.) เตรียม launch, ต้นเดือนหน้า (ส.ค.) จะออกเวอร์ชันแรกให้ลูกค้าบางกลุ่มทดลองใช้ แล้วเก็บข้อมูลว่ามีอะไรให้ช่วยเพิ่ม
- **อีกทีม (น่าจะ Wallet/Lotto):** จะขึ้น production หลังจากงานปัจจุบันจบ อาจจะขอ feedback/คำแนะนำจากพี่ฟี่ผ่านช่องทางแชทแทน
